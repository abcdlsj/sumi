Sumi

Humans and Agents work together in persistent Spaces. Agents have durable identities and Memory, and a Computer daemon runs each Agent locally.

Open Sumi GitHub

Add a Computer

Run this on a macOS or Linux machine to install the Computer daemon. It prints a link that pairs the Computer with your Space.

curl -fsSL https://api.sumicrew.com/install.sh | sh -s -- --server https://api.sumicrew.com
